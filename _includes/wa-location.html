{%- comment -%} WhatsApp buttons: ask the browser for the visitor's location and add a Google Maps link to the pre-filled WhatsApp message. If location is refused, unavailable or slow, a small notice explains how to send the location from inside WhatsApp, with a button that opens WhatsApp with the normal message. Turned on per page with `wa_location: true`, or for the whole site with `wa_location: true` in _config.yml. `wa_direct: true` (page or site) opens the WhatsApp app directly on phones (whatsapp://send) instead of going through the wa.me web page. `?nokonum` in the address shows the notice without asking for location (for testing). {%- endcomment -%} {%- if page.wa_location or site.wa_location -%} {%- endif -%}
